## 长文字的单元格

| 地点 | 说明 |
| --- | --- |
| 石桥 | 离镇子大约二十分钟的路程，桥身是用当地的青石砌成的，据说已经有两百多年的历史。过桥以后不要继续走大路，要从桥头右手边的小径下去，沿着溪水向上游走。 |
| 芦苇滩 | 看日出最好的位置。从入口处的观景台再往东走十分钟就到，视野开阔，水面上没有任何遮挡，清晨几乎没有别人。雨季的时候这里会被水淹没，只能远远地看。 |
| 瀑布 | 落差不大，但水量在雨后相当可观。站在对面的山脊上看，它只是一道很细的白线；走到跟前，水声大得要提高嗓门才能说话。 |

## 单元格里的行内样式

| 样式 | 例子 |
| --- | --- |
| 粗体 | **一定要带的东西** |
| 斜体 | *可带可不带的东西* |
| 删除线 | ~~已经取消的安排~~ |
| 行内代码 | `notes/route.md` |
| 链接 | [保护区的网站](https://example.com/reserve) |
| 高亮 | ==最容易走错的岔路== |
| 彩色高亮 | ==🟢备选路线== 和 ==🔴封闭路段== |
| 行内公式 | 坡度约为 $\frac{1}{12}$ |
| 几种混在一起 | **粗体**、*斜体*、`代码` 和[链接](https://example.com) |
