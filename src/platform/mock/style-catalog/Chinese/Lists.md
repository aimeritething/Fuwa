## 条目里的段落和代码块

1. 先安装依赖。

   这一步只需要做一次，之后除非依赖有变动，否则可以跳过。

   ```shellscript
   # 安装全部依赖
   pnpm install
   ```

2. 再启动开发环境。

   ```shellscript
   # 只启动前端，使用内存里的示例文件夹
   pnpm dev
   ```

3. 最后在浏览器里打开页面，确认一切正常。
